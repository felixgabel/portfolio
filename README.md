# README

This is my personal portfolio website. I built it to present my background, selected experience, and contact details as a frontend developer focused on modern, clear, and user-friendly web applications.

The portfolio is written in German.

## Notable Features

- Intersection Observer-based section tracking that keeps the active section synchronized with the URL hash
- Programmatic scrolling with protection against route-hash updates during navigation, including interruption handling for wheel, touch, and keyboard input
- Breakpoint-aware activation of section tracking for the desktop two-column layout
- Effect-scope lifecycle management that cleanly starts and tears down observers, watchers, and event listeners
- Route-level code splitting for the Impressum and not-found views
